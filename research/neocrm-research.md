## 1. 产品定位与核心业务

### 1.1 公司与定位
- 运营主体：北京仁科互动网络技术有限公司，发展历程始于 2011 年；官网自述「腾讯控股企业」（腾讯多轮战投，业内公认腾讯系 CRM 领头羊）。（来源 15）
- 定位演进：从「移动 CRM」→「营销服一体化 CRM」→ 2026 年宣布进入「AI CRM 2.0 时代」，主打 NeoAgent2.0 智能体矩阵，自述从「记录系统」转向「执行系统」。（来源 1、15）
- 机构认可：官方口径「连续十年成为唯一入选 Gartner 销售自动化（SFA）魔力象限的中国 CRM 厂商」；2019 年入选 Gartner aPaaS 推荐供应商名单；ISO20000/ISO27001；2024 入选独角兽榜单；信通院 AI CRM 成熟度模型参编单位。（来源 15）
- 客户规模：官方称服务「6000+ 大中型企业、数百家 500 强客户」；案例包括联想、海康威视、施耐德电气、沈鼓集团、上海电气、中外运、德力西、迪安诊断、山东临工、中升汽车、大金空调、博西家电等。（来源 1、2、4、15）

### 1.2 目标客户
- 主战场是**中大型/复杂业务企业**：销售云页面的痛点全部围绕「复杂型销售组织管理、复杂型产品报价、多维度交叉组织划分」等大企业议题；行业方案覆盖装备制造、高科技制造、电力设备、软件互联网、生命科学、现代服务、工业制造、汽车、快消、成长型企业、出海企业、国产替代共 12 类。（来源 1、2、13）
- 2025-2026 年起向两端延伸：
  - 向下：推出小微/个人 AI 产品「易启」（WorkBuddy 版 + 飞书版），「注册即用、零部署、免实施」。（来源 11）
  - 向外：国际站（neocrm.com）设 en/zh-hans/id 三语，新加坡/印尼设数据中心与东南亚总部，主打中国企业出海 + 本地化国际化。（来源 14、20）

### 1.4 版本与定价
- 官网不公开报价，全部引导「免费试用/联系销售」（来源 1）。
- 第三方信息（待核实）：销售云分 **专业版（约90元/人/月）、企业版（约180）、旗舰版（约360）、无限版（约600）**，按人/月订阅，12 个月起购；服务云同构；另有私有化部署定制报价（来源 25）。华为云市场 2023 年官方手册明确「基于销售易 CRM-**旗舰版**编制」，印证旗舰版是功能最全的公有云版本（来源 19）。
- 部署形态：公有云 SaaS（腾讯云/自有 IDC）+ 私有化部署 + 海外数据中心（新加坡、法兰克福、印尼，出海页称 1100+ 境内加速节点、250+ 境外节点覆盖 50+ 国家）。（来源 8、14）
- 文档站将产品划分为「**行业版产品**」与「**通用类产品**」两条手册线（来源 16、23），说明行业化以「行业版 + 模板」方式落地（详见第 6 节）。

### 2.2 营销云 / SCRM（来源 3、4）
- 引流获客：员工/群**智能活码**（扫码自动分配+欢迎语）、**智能名片**（自动记录访问轨迹）、微信客服（官网/公众号/小程序/视频号接入+机器人 7×24）、广告数据回流（DMP+平台投放，曝光-点击-留资-成交闭环）、市场活动小程序集客。
- 客户运营：360 度画像（企微标签+行为轨迹）、客户分层分类、**销售 SOP / 群 SOP**、企微朋友圈运营、素材中心（浏览埋点提醒销售）、智能话术推荐。
- 销售转化：营销任务管理（任务下发一键执行）、企微侧边栏内直接创建商机/订单/合同/工单。
- 会话智能：**会话存档合规**、敏感词行为质检、智能打标签、智能会话总结。
- 数据：渠道 ROI 分析、BI 看板、数字客户空间。

### 2.3 服务云 / 现场服务云（来源 6；文档站将「客户服务云」「现场服务云」分列两本手册，来源 23）
- 全渠道接入：电话、APP、网页、H5、公众号、小程序、邮件、短信，一个工作台统一处理。
- 工单管理：预制规则自动分配、工作流、审批流、**SLA 规则**；工单类型/字段/分配规则可自定义，支持合并、转移。
- 客户自助：帮助中心小程序、自助报修（预约安装/保养/返修，进度查询）、智能机器人（知识库匹配）。
- 现场服务：**派工调度**（智能推荐、甘特图调度台）、标准作业流程、自动生成服务报告、工程师 APP/小程序（拍照视频留证）、返修寄修（故障代码、维修模板、物流追踪、在线支付）。
- 备件管理：领用/退货/调拨/盘点、库存预警、零部件流转跟踪。
- 设备档案：销售到服务全生命周期档案、服务合同与维保计划。
- 服务商管理：注册准入、档案签约、服务商备件仓、服务过程跟踪、**费用自动结算**（结算审批流+自动结算规则）。
- 服务产品化：满意度评价/自动回访计划、服务套餐与复购（服务团队向利润中心转型）。

### 2.4 伙伴云 PRM（来源 5）
- 渠道生命周期：准入→评估→协议→退出全流程数字化；按产品/价格/区域的**经销商授权**。
- 渠道订货：**订货商城**（在线下单、发货物流实时可见）、促销管理（买赠/打折/满减/特价）、多账户（现金/返利/积分/信用）、**返利管理**（方案制定→计算→确认→上账）。
- 渠道协同：**商机报备**（防撞单飞单）、拜访管理、**对账管理**（账单自动生成→在线申诉→在线确认）。
- 渠道赋能：经销商门户（新闻公告）、知识库培训、**企微上下游**（上下游群聊+数字渠道空间小程序）。
- 渠道经理 Agent：智能拜访规划（客户清单/日程/路线）、拜访策略推荐、拜访录音自动总结回填。

### 2.5 智能分析云 NeoBI（来源 7）
- 四种形态：全员 BI、敏捷 BI、嵌入式 BI、协同 BI；官方称 Gartner SFA MQ「可视化分析能力第一」。
- 业务用户：拖拽自助分析、分行业分析模板、**数据穿透**（分析一键跳转业务模块操作）、20+ 可视化图形。
- 管理：多端呈现（PC/Mobile/企微/大屏）、数据订阅推送、多维度目标管理闭环、智能预警。
- 分析师/IT：与 CRM 原生一体数据对象（免配置）、共享空间协同、数据权限与业务系统一致、任意数据源接入、元数据管理（字段级血缘）、脱敏/水印/日志。

### 2.6 Data Cloud / CDP（来源 9）
- 多源接入：CRM 业务数据（开箱即用、免建模）+ 工商数据（3000 万企业标签）+ 行为数据（营销服互动亿级行为）。
- 平台能力：存储计算分离、海量实时计算、支撑 NeoAgent 推理负载；打通 NeoAgent 平台自动调用业务 API、触发工作流、执行脚本。
- 标签画像：智能标签引擎（属性/行为/分值/统计指标/组合规则）、细分群组、客户 360 画像。
- 智能应用：智能客户推荐（赢单客户种子相似推荐）、智能线索评分。
- 安全：租户数据隔离、动态脱敏、全链路审计、毒性指令拦截。

### 2.7 NeoAgent2.0（来源 10）
- 底座：**业务语义层**（业务语义本体）+ **可信数据层**（Data Cloud）。

## 3. 核心业务流程的产品支撑

### 3.1 L2C 主流程（线索→回款）（来源 2、17、18）
1. **线索获取**：智能拓客（工商数据）、多渠道广告 API 接入、市场活动/表单/活码/名片扫描、Web 表单——「多渠道接入，全渠道线索归集」。
2. **线索分配**：线索公海池 + 自定义分配/回收规则（分组成员可见性、循环回收无进展线索）；NeoAgent 线索智能评分排序。
3. **线索转化**：一键/批量转化为客户+联系人+商机（SFA-04 线索转换），转化规则可配置。
4. **客户经营**：客户 360、查重规则去重、客户审批与变更单管控、客户公海池再分配。
5. **商机推进**：可配置销售阶段与推退规则、阶段任务/关键事件、作战地图与推进排行榜、AI 健康度评估与行动建议。
6. **报价/CPQ**：价格表+折扣审批管控，复杂产品选装选配在线配置核价。
7. **合同/订单**：合同审批流与变更单、订单生成、收入确认计划。
8. **回款/开票**：回款计划、回款记录核销、开票，形成「销售最后一公里」闭环。
9. 全程支撑：审批流/工作流、目标管理与业绩拆分、BI 销售漏斗与预测、仪表盘预警。

### 3.2 售后服务流程（来源 6）
- 报修受理（全渠道/自助小程序）→ 客户 360 与设备档案调取 → 工单自动派发（规则+SLA）→ **派工调度**（技能等级/位置/产品类型多维匹配，智能推荐+甘特图）→ 工程师移动端现场作业（签到、作业 SOP、备件领用、拍照留证、服务报告、客户签名）→ 备件/库存联动 → 费用结算审批 → 满意度回访 → 服务合同/维保计划续约。服务商模式下增加：服务商准入签约、服务商备件仓、过程跟踪、自动结算。

### 3.3 渠道伙伴流程（来源 5）
- 招募准入（生命周期管理）→ 授权（产品/价格/区域）→ 赋能（门户+知识库+企微上下游群）→ 协同售单（**商机报备+冲突裁决防撞单**、联合拜访）→ 在线订货（订货商城+促销）→ 履约对账（自动账单+在线申诉确认）→ 返利上账（方案→计算→确认→上账，多账户体系）→ 绩效复盘。

### 3.4 营销获客流程（来源 3）
- 投放（腾讯 DMP+广告回流）→ 活码/活动集客 → 线索池与规则分配 → ROI 渠道分析反哺投放 → 企微私域培育（SOP/素材/朋友圈）→ 行为埋点提醒跟进 → 转商机/订单 → 老客复购运营。

## 4. 平台与配置能力（PaaS = Neo-Platform）（来源 8、17、22）

### 4.1 四大能力板块（官网 /paas 官方口径）
1. **高效应用构建（低代码）**
   - 可视化业务建模：拖拽完成复杂业务建模（自定义对象/字段/关系），面向全业务领域 + 数据模型自管理。
   - 统一权限体系：**RBAC + ABAC 双模型**，功能权限与数据权限多层次多维度管控（对应 Admin 系列文档：用户与权限→角色权限→职能权限→数据权限多维度，见第 7 节）。
   - 业务自动化引擎：智能流程引擎（**可视化流、工作流、自动流**三类）+ 事件驱动规则引擎（可视化规则配置、丰富规则事件）；Admin 文档还有校验规则（Admin-08）、查重规则（Admin-09）、关联关系（Admin-10）、引用字段（Admin-11）、主子明细（Admin-12）等对象级配置能力。
   - UI 与多端：图形化 UI 页面开发、灵活品牌定制；产品级对接**企业微信、钉钉、飞书、腾讯会议**；服务小程序。
2. **灵活定制开发（pro-code）**：业务操作/逻辑/流程/UI 全代码定制；**Java + H5 开发套件与 SDK**；沙盒环境 + 持续交付，开发制品跨环境一键迁移。PaaS-08「业务逻辑代码」、PaaS-02「触发器（Trigger）」、PaaS-09「NEO-UI、NEO Extension、RPA」表明扩展点包括触发器、前端 UI 组件、扩展应用与 RPA。
3. **集成及生态连接**：
   - 身份集成：企业级统一认证、账号全生命周期、预置上百款主流应用认证组件；PaaS-07 单点登录。
   - 数据集成：批量导入导出、批量数据处理接口（PaaS-04 Bulk API）、大规模双向实时同步。
   - API 体系：官方列明 **Open API、Bulk API、XOQL API、Meta API** 四类（PaaS-03/04/05/06 分别对应 Open API、Bulk API、XOQL、自定义 API）——XOQL 为自研查询语言，Meta API 暴露元数据。
   - 应用集成：跨系统业务集成平台（图形化配置+开箱即用连接器）；预置第三方组件：工商信息、标讯、支付、电子签章、物流、OCR 自动识别录入。
4. **企业级技术基座**：多层安全（CCRC 认证、水印、加密、脱敏）、**全链路多活高可用架构**、容器化弹性伸缩、跨双活主备集群+跨区域备份容灾、全球网络加速、海外数据中心支持合规出海。页面未直接使用「元数据驱动架构」字样，但有 Meta API 与统一元数据管理表述（待核实在帮助中心中的确切提法）。

### 4.2 权限体系细节（Admin 系列文档目录佐证）
- Admin-01 用户与权限 / Admin-02 角色权限 / Admin-03 职能权限 / Admin-04 数据权限多维度：权限按「用户-角色-职能-数据维度」分层；结合官网「RBAC+ABAC」表述，可推断数据权限支持多维度（组织、区域、业务线等）动态控制。

## 6. SaaS 标准化设计思路（观察与推断）

1. **标准开箱能力**：L2C 全流程对象（线索/客户/联系人/商机/报价/合同/订单/回款）、公海池机制、SLA 工单、派工调度、订货商城与返利、自助分析 BI 模板、预置行业 BI 模板与驾驶舱（「最佳实践预置，开箱即用」）、预置集成组件（工商/电子签/支付/OCR）。华为云市场版手册展示的旗舰版即为一套「装完即可用」的标准流程配置样例（含客户变更单、机会年度预测等进阶标准功能）。（来源 2、6、7、19）
2. **配置化能力（无代码）**：自定义对象/字段/页面布局、校验规则/查重规则/引用字段/主子明细、审批流/工作流/自动流、公海规则、SLA、报价折扣管控、目标维度、数据权限多维、企微侧边栏配置等——产品将「大企业差异性」尽量压缩进配置层。（来源 8、17）
3. **低代码/全代码层**：触发器、Java+H5 函数与业务逻辑代码、自定义 UI 组件（React/Vue）、自定义 API、RPA、XOQL 查询——承接配置层覆盖不了的长尾。（来源 8、17、22）
4. **版本分层体现标准化**：专业版（标准销售管理）→ 企业版（+ 更多流程/权限/集成）→ 旗舰版（+ CPQ、服务、PaaS 高级能力；华为云手册即基于旗舰版）→ 无限版/私有化（第三方口径，待核实）。小微端则以「易启」完全免配置、AI 优先的独立产品线承接，与主产品的「重配置」形成两端。（来源 11、19、25）
5. **行业化落地方式**：a) 12 个行业解决方案页（装备制造/高科技/电力/软件/生命科学/现代服务/汽车/快消/成长型/出海/国产替代）作为「行业最佳实践包」营销与交付载体（装备制造页明确给出：复杂集团架构管理、大型设备交付项目管理、选装选配 CPQ 三大行业化亮点）；b) 文档站单列「行业版产品」手册线（与通用类产品并列）；c) BI 分行业分析模板。第三方称有「60+ 行业解决方案模板包」（cnblogs 2025，**待核实**）。（来源 1、13、23、25）
6. **AI 的标准化位置**：NeoAgent2.0 不作为附加插件而是把「业务语义层 + Data Cloud」做成平台底座，各业务云预置角色化 Agent（销售/客服/渠道/分析师），客户再通过 Agent 开发平台自建——即「预置智能体 + 平台自建」两层。（来源 9、10）
