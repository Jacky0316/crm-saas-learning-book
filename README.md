# CRM SaaS 产品学习书

以 **纷享销客（FXiaoke）× 销售易（Neocrm）** 为双案例，系统讲清"一款商业化、标准化的 CRM SaaS 是如何搭建与设计的"。

## 怎么读

仓库里的 `CRM-SaaS-产品学习书.html` 是一个**单文件、零外部依赖**的交互式学习手册：

```bash
git clone https://github.com/Jacky0316/crm-saas-learning-book.git
# 克隆后直接双击打开 CRM-SaaS-产品学习书.html 即可（离线可读）
```

内置交互：

- **产品视角切换**：纷享销客 / 双产品对照 / 销售易 三态过滤，可专学一家或逐条对比
- **12 张手绘风图示**：L2C 泳道图、9 大对象 ER 图、六层架构、生态地图、标准化光谱等
- **术语弹层**：52 条术语，正文虚线词点击即解释
- **可信度角标**：✅ 一手官方 / ⚠️ 口径存疑 / ❓ 第三方转引，每节附来源链接
- **自测清单**：18 项学习目标可勾选，进度与偏好（视角/深浅色）本地自动保存

## 全书结构

| 章节 | 内容 |
|---|---|
| 第 0 章 导读 | 为什么选这两家、术语地图、来源与可信度说明 |
| 第 1 章 核心业务 | CRM 经营什么、双雄定位、商业化模式（订阅×版本×版块×实施） |
| 第 2 章 系统架构 | 六层架构、元数据驱动、RBAC+ABAC 权限、AI 原生架构、安全合规 |
| 第 3 章 核心业务流程 | L2C 六阶段泳道、订单后延伸（三类立应收）、服务与渠道闭环 |
| 第 4 章 核心功能 | 对象模型 + 销售域/交易域/营销域/服务域/渠道域/分析与 AI |
| 第 5 章 生态打造 | 开放平台、超级 App 路线、上下游网络（企业互联 vs 伙伴云） |
| 第 6 章 标准化设计 | 四级标准化光谱、九项具体设计、通用搭建公式与本土化增量 |
| 附录 | 术语表 · 双产品功能对照总表 · 来源清单 · 自测清单 |

全书记忆主线（通用搭建公式）：

```
标准对象模型 → L2C 业务流程 → 平台配置层 → 版本分层 → 行业模板 → 生态扩展
```
